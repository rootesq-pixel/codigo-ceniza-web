Cómo instalar el APK

  1. Pulsa Descargar para Android y descarga el archivo APK desde Gofile.
  2. Abre el archivo descargado. Si Android lo bloquea, ve a Ajustes → Seguridad / Aplicaciones → Instalar apps desconocidas y permite a tu navegador o gestor de archivos instalar apps (permitir orígenes desconocidos).
  3. Pulsa Instalar y abre Código Ceniza.
  4. Opcional: tras instalar, puedes volver a desactivar el permiso.
